# Quokka Academy - Neo-Brutalist Design System

Quokka Academy is an interactive English learning platform for children featuring certified teachers and Pip the Quokka mascot. The application is built with a Playful Neo-Brutalist design language that combines thick 3.5px solid dark ink borders, hard zero-blur offset shadows, and a warm cream canvas with high-contrast pastel pop colors.

Interactive components like buttons, cards, and tags feature tactile physical press micro-interactions where shadows compress from 5px down to 2px when clicked. Spacing, typography, and responsive grid layouts are designed to give young learners and parents a joyful, high-energy learning environment while preserving high readability and clear visual hierarchy across all devices.
